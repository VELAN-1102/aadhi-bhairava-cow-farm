# Contributing to Aadhi Bhairava Cow Farm

Thank you for contributing to our smart dairy management system!

## Coding Standards

- **TypeScript Strict Checking**: Maintain zero compilation warnings or type-assertion errors.
- **SOLID & Clean Architecture**: Keep all business models within service packages and decouple db updates via repositories.
- **Git workflow**:
  - Always base branch creations off `develop`.
  - Prefix branch names: `feature/` for additions, `fix/` for bugs, `docs/` for manuals.
  - Submit Pull Requests targeting `develop` for validation before main merging.
